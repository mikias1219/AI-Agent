# AURA v1.0

**Date:** 2026-11-12

## Highlights

- Safe-by-design personal agent: ToolRegistry gate, durable approvals, untrusted external content.
- Today / Inbox, Memory, Automations, Google read/write tools, Telegram reply gate, MCP + web tools.
- Offline evaluation harness (25+ scenarios) with CI badge; lightweight GenAI tracing and extended health.
- Public `/demo` workspace on an isolated SQLite database with SIMULATED external actions.

## Upgrade

```bash
cd backend
alembic upgrade head
```

Set `DEMO_DATABASE_URL` to a path different from `DATABASE_URL` if you expose `/demo`.

## Known limits

- Token counts on runs remain optional until providers report usage.
- Live cloud demo hosting is optional; `/demo` works against any deployed API with demo routes enabled.
